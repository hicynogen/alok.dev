01Never trust the input.+

Browser validation helps people. Server validation protects the application. Check types and lengths, set request limits, and use parameterized database queries.

APPLIED HERE / CONTACT API
02Give access deliberately.+

Only expose what visitors need. Keep secrets and inbox data outside the public asset directory. A private inbox does not need a public listing endpoint.

APPLIED HERE / PUBLIC ASSET ALLOWLIST
03Make failure useful.+

A failed request shouldn’t erase someone’s message. Clear feedback, preserved input, and an alternative contact route make an interface more resilient.
